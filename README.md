# Riano 碎碎念

星空背景的个人小站。栏目和常见个人博客一样：碎碎念列表、关于、友链、联系。

## 写碎碎念

双击 `启动写作台.bat`。浏览器会打开 http://127.0.0.1:8787/editor/

- 查询：左上角搜索标题、分类或正文
- 新建：点「新建」，写完点「保存」
- 修改：在左边点开一篇，改完再保存
- 删除：打开一篇后点「删除这篇」
- 图片、GIF、视频：点对应按钮上传，单个文件不超过 45MB

保存后，本机打开 http://127.0.0.1:8787/ 就能看到。点「发布到 GitHub」后，https://riano5589.github.io/ 会在一两分钟内更新。

写作台只在自己的电脑上运行，不会公开到网上。

友链仍然写在 `js/friends.js`。
